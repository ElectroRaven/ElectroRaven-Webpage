Language Design Project

Leap is a beginner-first programming language with clean, human syntax.

Leap kombiniert eine klare Syntax mit didaktischem Fokus: Man kann dieselben Konzepte in English, Deutsch und Norwegisch schreiben. So bleibt die Lernkurve flach, waehrend Variablen, Bedingungen, Schleifen, Funktionen und Dateioperationen praxisnah gelernt werden.

Unten ist die Syntax in einzelne Themen aufgeteilt, damit jede Funktionalitaet von Leap separat und sauber nachvollziehbar bleibt.

Konsolenausgaben

Variablen und Booleans

EN | DE | NO

Dynamische Werte mit sprachspezifischen Literalen.

y = 67;

falschBool = falsch;

Mathematische Operatoren

Arithmetik

Direkt im Ausdruck oder in Ausgaben nutzbar.

let x = 41.5 + 1.2;
y = 67;

print("Modulus von y durch 66: " + (y % 66));
print("Ergebnis X + Y: " + (x + y));

Bedingungen

EN | DE | NO

if/falls/hvis mit else-Zweigen in allen Sprachmodi.

if(j == 30){
    print("j ist 30");
} else if(j == 41){
    print("j ist 41");
} else {
    print("j ist " + j);
}

falls(z == 40){
    ausgeben("z ist 40");
} sonst {
    ausgeben("z ist nicht 40");
}

hvis (alder >= 18) {
    skriv("Voksen");
}

Schleifen

for | while | repeat

Klassische Kontrollstrukturen mit lokalen Sprachvarianten.

for(i = 0; i < 5; i = i + 1){
    print("i ist: " + i);
}

während(q < 3){
    ausgeben("q ist: " + q);
    q = q + 1;
}

gjenta (r < 3) {
    skriv("gjenta r=" + r);
    r = r + 1;
}

Arrays und Zugriff

Listen, Matrizen und Updates per Indexnotation.

let names = ["Anna", "Ben", "Cara"];
let matrix = [

    [4, 5, 6],
    [7, 8, 9]

matrix[0][1] = 42;
print("First name: " + names[0]);

Funktionen

EN | DE | NO

Eigene Funktionen mit return/zurück/retur.

def greet(name) {
    return "Hello " + name;
}

funktion begrüß(name) {
    zurück "Hallo " + name;
}

funksjon sum(a, b) {
    retur a + b;
}
